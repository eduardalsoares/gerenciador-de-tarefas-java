# Gerenciador de Tarefas

## Sobre o projeto
Sistema para organização pessoal que permite registrar, acompanhar 
e concluir tarefas do dia a dia.

## Funcionalidades
- Cadastrar tarefas com título, descrição, data limite e status
- Listar todas as tarefas registradas
- Marcar tarefas como concluídas
- Editar dados de uma tarefa
- Excluir tarefas
- Filtrar tarefas por status ou data

## Tecnologias
- Java
- Eclipse IDE

## Como executar
1. Clone o repositório
2. Abra no Eclipse como Java Project
3. Execute o arquivo `Main.java`

## Estrutura do projeto
- `Tarefa.java` — modelo de dados da tarefa
- `GerenciadorDeTarefas.java` — lógica e funcionalidades do sistema
- `Main.java` — menu principal e interação com o usuário
